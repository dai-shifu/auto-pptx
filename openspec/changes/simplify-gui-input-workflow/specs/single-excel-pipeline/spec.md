## ADDED Requirements

### Requirement: 通过浏览选择输入文件

GUI SHALL 通过「浏览」选择模板 PPT 和 Excel 文件。路径框 SHALL 只读，不接受直接输入或粘贴来换文件。取消选择 SHALL 保持当前状态。

#### Scenario: 切换或取消选择文件

- **WHEN** 用户通过「浏览」选中文件
- **THEN** GUI 显示所选路径并刷新对应输入
- **AND** 再次打开浏览对话框但取消时，路径、预览与勾选保持不变

### Requirement: GUI 生成前要求有效模板列

GUI SHALL 按当前工作表有效的模板列生成，SHALL NOT 在模板列未选中或不属于当前工作表标题时调用生成入口重新识别。此要求不改变直接调用生成模块时的行为。

#### Scenario: 未选模板列但其他设置有效

- **WHEN** 文件、工作表和勾选行都有效，但「模板列」未选中，用户点击「生成 PPT」
- **THEN** GUI 提示用户在「模板列」下拉框中选择用于匹配 PPT 模板的 Excel 列
- **AND** 不调用生成入口，不输出文件，不保存配置

#### Scenario: 自动识别已选中有效模板列

- **WHEN** GUI 已自动选中当前标题中的有效模板列，且生成所需的其他设置有效
- **THEN** 用户可以直接生成，不需要再次选择同一列或先运行只读检查
