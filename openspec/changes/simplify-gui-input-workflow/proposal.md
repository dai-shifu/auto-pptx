## Why

路径可修改，但预览和勾选不一定随之刷新。加载失败也可能留下旧状态。日常约 100 多行，当前整表预览足够；应减少输入分支和重复刷新，而不是增加分页或新的布局。

## What Changes

- **BREAKING（GUI 操作）**：将模板 PPT 和 Excel 路径框设为只读。文件只通过「浏览」选择，不再支持粘贴路径来换文件。
- 让勾选跟随已成功加载的数据。换 Excel、Sheet 或有效标题行时清空；只换模板或映射且数据不变时保留。Excel 加载失败时清空旧预览和勾选，不能继续生成。
- 点击「生成 PPT」时，若没有有效模板列，提示手动选择，不让生成入口重新猜测。保留直接调用生成模块时的现有行为。
- 移除无用的映射来源标记。标题行识别与预览共用一次工作表数据读取；模板列切换不改变可见列时不重建预览。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `single-excel-pipeline`：限定 GUI 的文件选择入口，并要求生成前有当前有效的模板列。
- `visual-row-selection`：规定勾选的保留、重置和 Excel 加载失败的行为。
- `data-preview-columns`：可见列不变时不重建预览，切换模板列时继续保留勾选。

## Impact

涉及 `src/gui.py`、当前工作表读取、定向测试和操作说明。保留映射区、整表预览和悬停提示。不改配置格式、生成规则或发布方式。旧 Excel 兼容接口由独立变更处理。
