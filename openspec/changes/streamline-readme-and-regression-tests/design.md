## Context

`test_generator.py` 和 `test_integration.py` 用同一套合成样本运行相同的三个场景，但成功用例的断言不同。配置和 Excel 读取测试也有重复调用。README 在快速开始前后重复链接示例，并两次说明如何勾选数据行。

## Goals / Non-Goals

**Goals:** 每个重复场景只执行一次，保留原有断言并加强生成回归检查。让用户从快速开始找到示例、完成生成并找到成品。

**Non-Goals:** 不改运行时行为、应用入口、工作流、GUI 测试、其他文档或样本文件。不引入新的共享测试框架。

## Decisions

- 将三个端到端场景保留在 `test_integration.py`。成功用例沿用共享样本，逐页检查模板标记、代表性文本和表格值，并断言页数。使用不同于模板顺序的行选择，让页序断言能发现意外排序。空选择和未知工作表各匹配自己的错误，并检查输出不存在。其余生成测试保留在原文件。
- 在 `test_config.py` 中合并缺失文件用例，同时检查默认值和不落盘；已有配置测试使用 `tmp_path`。不合并“文件不存在”和“已有文件缺字段”。在 `test_excel_reader.py` 中把空值断言并入同一次成功读取，单独保留文件不存在用例。
- 在快速开始保留一个日报示例入口，把勾选操作集中到生成步骤，图下保留界面说明链接。不删除图片、中英文切换、配置说明入口或成品位置说明。

## Risks / Trade-offs

- 删除重复测试可能误删唯一断言。先核对并迁移断言，再删重复用例。独立保留未映射警告、零页失败和样本契约测试。
- 样本、GUI 和工作流已有其他变更。实现只修改本提案列出的文件；跑定向测试后，在有真实 Tk 显示的环境运行全量测试，不能把跳过记作通过。
