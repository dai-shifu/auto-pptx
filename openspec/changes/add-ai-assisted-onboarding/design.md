## Context

现有 README 从选择配套文件开始。公开日报样例可以演示一行生成一页，但新用户换上自己的文件后，需要知道问题出在模板列、数据映射还是模板内容。

GUI 管理工作表、标题行、模板列、映射和勾选行。模板索引、占位符扫描、自动检测及生成已有非 GUI 模块。现有模板元数据汇总整份演示文稿的占位符，缺少用于解释具体数据行的「页 → 占位符」关系。

## Goals / Non-Goals

**Goals:**

- 用公开样例和两种映射关系解释工作原理。让用户不依赖 AI 也能完成首次生成。
- 用当前设置检查陌生文件，区分实际匹配、自动建议和需要确认的字段含义。
- 在本机展示检查结果，让用户选择是否将精简摘要交给自己的 AI。
- 提供可选的轻量 Skill，复用同一份入门规则。

**Non-Goals:**

- 不添加 AI API、在线服务、CLI、MCP、任务文件或第二个 exe。
- 不改变保存配置和手动选择优先级，不让检查自动修正设置，也不重新设计日常生成流程。
- 不渲染 PPT，也不验证文字溢出、版式或字段业务含义。

## Decisions

### 检查当前设置，不另设一套自动模式

从 GUI 获取工作表、标题行、模板列、Excel 列 → PPT 占位符映射和已勾选的 Excel 实际行号。共用生成时的选项提取逻辑，保留用户明确设为「不映射」的选择。检查显示当前有效设置；自动检测结果放在单独的建议区，不能覆盖当前值。首版不另加「忽略已保存设置」模式：它会让两套相似结果更难区分。

若未勾选数据行，只检查结构和映射，并提示先勾一行再看选页结果。不隐式全选。若模板列未确定，不承诺预计页数；给出需要确认的模板列或重新选择的提示。生成仍保留原有回退行为。

### 检查逻辑不依赖 GUI，也不试生成

从现有模板扫描提取每页的原始页号、模板标识和可替换占位符。复用生成使用的模板名匹配、半角 `/` 分隔、重复标识取首个及现有校验规则；用共享逻辑取代可能导致分叉的规则复制。模板列并列时，报告候选列及匹配依据，不改变现有自动选择顺序。保留生成器的保存、克隆与警告行为。

对所选行按现有规则列出匹配页、预计页数及按行定位的问题。分别报告未映射（占位符保留）、已映射但单元格为空（填空字符串）、模板部分匹配（保留匹配页）和未匹配（跳过）。报告按工作表、行号或模板页定位提供下一步建议。新检查模块不保存配置、不写文件、不修改已加载的模板，也不接触网络或剪贴板。

### 分开本机报告和分享摘要

GUI 在用户主动检查时读取当前输入，展示本机结果；保留现有工作区的最小窗口操作约束。本机结果可以定位原始值，摘要使用结构化字段生成，不直接复用日志或异常原文。分享摘要默认省略输入路径、文件名和单元格正文，包括未匹配的模板列原值；保留行号、问题类型和用户可审阅的结构名称。摘要可在复制前修改；只有用户显式复制才写入剪贴板。未加载或读取失败时不展示上一对文件的结果。

### 一份指南，两种 AI 使用方式

README 链接到入门指南；指南是面向用户的工作规则和 AI 提问示例的来源。沿用仓库公开样例，用「日报数据」工作表、标题行 1、模板列「模板」、Excel 第 2 行演示生成一页「日报总览」。继续保留现有五页演练。无需在 exe 中打包示例。

公开分发 `skills/auto-pptx-onboarding/SKILL.md`。它只描述何时使用、先读哪份指南、怎样解释摘要及如何回到 GUI。只安装 Skill 的用户也能找到公开指南，不需要克隆应用仓库。Skill 无执行脚本，不安装依赖、不上传原始文件、不承诺调用首版未提供的接口。单元格、列名和模板名只是待分析的数据，不是交给 AI 的操作指令。

## Risks / Trade-offs

- 检查和生成算出不同结果 → 共享解析与校验规则；用公开样例和合成异常样本对照页数、顺序及警告。预计页数只描述规则匹配，不保证渲染或保存成功。
- 双方使用了不同设置或报告过期 → 打开检查时读取当前数据和设置；把报告标为本次检查时的快照，在更改文件或设置后提示重新检查。
- 新按钮挤占工作区 → 用可关闭的检查窗口承载详情，在最小窗口验证选文件、勾选和生成仍可操作。
- AI 把猜测当结论，或用户分享敏感名称 → 分离事实与建议；复制前预览并允许编辑，提示结构名称也可能敏感。

## Migration Plan

新增入口随现有 Windows exe 发布；GitHub 仓库提供公开样例和可选 Skill。旧配置无需迁移，不新增发布附件。若撤回变更，既有配置和 GUI 生成流程仍可使用。

## Open Questions

无首版阻塞项。本机 AI 直接调用的 Windows 发布形态和 MCP 客户端需求在后续变更决定；本变更的检查能力不绑定传输方式。
