## Context

「检查当前设置」独立于生成，读取同一组设置生成报告，并可预览和复制摘要。公开样例和模板规则本身不依赖它。

## Goals / Non-Goals

- 保留公开样例和两种映射关系的说明，帮助用户直接完成首次生成。
- 完整移除独立检查和摘要，不改生成中的校验、警告、模板匹配或映射优先级。
- 不引入其他预检入口，不迁移配置或改变发布方式。

## Decisions

- 底栏保留生成按钮和状态。保留 GUI 提取当前工作表、标题行、模板列、映射和勾选行的逻辑；设置不再依赖检查类型，也不再收集仅供检查报告展示的「明确不映射」列表。手动「不映射」本身继续生效。
- 删除独立检查和分享模块、报告专用数据和测试。自动检测仍按原顺序决定并列选项，模板索引仍保留重复标识的第一张页并警告。保留生成仍使用的公共解析和校验逻辑。
- 从中英文 README 链接到入门指南。用「日报数据」工作表、标题行 1、模板列「模板」和 Excel 第 2 行演示一页「日报总览」。用户换用自己的文件后，可先生成一行，按错误或警告排查。

## Risks / Trade-offs

- 不再提供生成前的预计页数或字段来源报告；小范围试生成和现有警告是文档中的排查方式。
- 检查曾复用生成设置和匹配逻辑。用 GUI 直接生成、生成校验、自动检测和公开样例回归测试保护现有行为。

## Migration Plan

不需要配置迁移，不改已发布的 exe 或样例文件。后续构建不再包含独立检查功能。
