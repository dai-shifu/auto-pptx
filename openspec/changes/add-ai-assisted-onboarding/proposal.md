## Why

公开日报样例能帮助新用户理解怎样选页和填值。原先为入门新增的独立检查与分享流程不是生成所需，现将范围收窄为一页样例和使用指南。

## What Changes

- 保留中英文 README 中的样例入口，用现有公开样例演示「只选一行，生成一页」，说明选页和填值的区别。
- 移除 GUI 的「检查当前设置」入口、只读报告、分享摘要及其专用代码和测试。不新增替代入口或独立检查步骤。
- 更新中英文入门和相关文档；遇到问题时按生成的错误或警告排查。

## Capabilities

### New Capabilities

- `sample-onboarding`：使用公开样例完成首次生成，并理解 Excel 数据与 PPT 模板的两种对应关系。

### Modified Capabilities

- `gui-workspace-layout`：底栏仅保留「生成 PPT」和状态文本。

## Impact

影响 GUI、独立检查代码、相关测试和中英文说明。不改现有生成规则、校验与警告、配置格式、样例文件或发布附件。
