## ADDED Requirements

### Requirement: 新用户可以用公开样例生成第一页
项目 SHALL 在中英文 README 提供示例入口，并通过入门指南分别解释「Excel 模板列的值 → PPT 模板页」和「Excel 数据列 → PPT 占位符」。指南 SHALL 指出模板名和占位符名不是同一类标记，说明固定页不会自动保留、不替换图表数据，并引导用户按实际生成的错误或警告排查。

#### Scenario: 用户还没有自己的模板和数据
- **WHEN** 新用户按指南打开公开的日报样例
- **THEN** 指南给出工作表、标题行、模板列和映射设置，并引导用户只选 Excel 第 2 行
- **AND** 用户能用现有 GUI 生成一页「日报总览」，不需要 AI、项目源码或 Python 环境
