## Context

GUI 预览、只读检查和生成都从单个工作簿读取数据。旧接口不在这些路径上。双 Excel 改为单 Excel 时，曾特意保留这些接口供源码调用方兼容；现在退役这层兼容。

## Goals / Non-Goals

**Goals:** 移除旧读取和项目编号联查接口、对应测试以及现行兼容说明。验证单 Excel 流程仍按勾选行生成。

**Non-Goals:** 不改 GUI、自动检测、映射优先级、空值处理、模板标记、配置或成品格式。不修改已提交的样本和历史记录。

## Decisions

- 直接删除旧入口，不加别名或弃用分支。保留 `read_sheet_rows()`、`generation_headers()` 和 `cell_text()`。需要迁移的脚本应按工作表、标题行和 Excel 实际行号使用现行生成入口，不再按项目编号查找。
- 删除只调用退役接口的用例。优先复用现有集成用例验证无项目编号也能生成，以及中文列名、空值、输出页数和顺序；如果缺少重复项目编号的覆盖，在现行生成层补一个最小用例。
- 检索 README、使用与开发文档、公开 Skill、现行规格和未归档变更。删除把旧接口写成现行支持的说明。`sanitize-for-public-release` 中的兼容保留仅属于当时的范围，澄清这点，不把历史决定改写成当时已删除。归档中的旧方案保留为历史；现代示例中的「项目编号」仍可作为普通列名。

## Risks / Trade-offs

- 仓库外脚本可能直接导入退役接口 → 在提案中标明源码不兼容及迁移方式；不为已退出的业务保留代码。
- 删除旧读取测试可能误删仍有效的读取约束 → 先核对单 Excel 的现有覆盖，再删旧测试；用有显示的环境运行全量测试。
