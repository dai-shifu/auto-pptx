## Context

现有应用支持单 Excel、按行选模板、文字与表格替换。用户确认场景为蛋白表达与纯化日报，实验图片手动处理。现有小型 fixture 用于回归测试，另有发布流程变更正在工作区进行。

## Goals / Non-Goals

**Goals:** 提供设计统一、可编辑、可复现的五页日报及简洁操作文档，保持现有生成器兼容。

**Non-Goals:** 不增加图片替换、统计汇总、动态配色、自动图表或科学结论判断，不改动现有 fixture。

## Decisions

1. 示例独立置于 `examples/bio-daily/`，使用三页模板和五行数据；全部数据在构建脚本中定义，并以现有 `generate()` 产生五页成品。
2. 使用 16:9、深蓝/青绿/暖白主题，文字、表格、装饰均由原生 PPT 元素构成；统一使用适合中英文的字体。实验图片区域只作手动编辑提示，不使用未映射图片占位符。
3. 项目页包含表达与纯化进展、三项结果及下一步；总览和风险页由独立数据行填写，避免暗示软件会跨行汇总。状态为文字，颜色不随数据自动变化。
4. 脚本支持输出至指定目录，默认输出示例目录；预览由实际生成成品渲染，不能用与 PPT 不同的网页或手绘图替代。渲染工具仅用于维护，无需加入运行时依赖。
5. README 负责介绍与入口，使用指南集中记录规则与排错，示例 README 解释字段和复现。保留发布流程文档的现有约定，仅补充示例更新要求。

## Risks / Trade-offs

- [长内容溢出] → 使用保守字号和留白，说明建议字数，检查较长项目名称与多行结论。
- [字体替换改变版式] → 指定常见中文字体并记录渲染环境；Windows 成品仍应在目标 Office 中抽查。
- [公开素材泄露信息] → 全部示例独立虚构，清理 Office 属性，不包含真实实验图片。
- [与发布流程并行变更冲突] → 不改写其脚本，文档以最终现有文件复核，不将新示例冒充为已打入 Windows 包的资源。
