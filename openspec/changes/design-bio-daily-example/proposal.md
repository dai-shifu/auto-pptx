## Why

项目需要贴合蛋白表达与纯化日报的完整示例，展示现有 Excel 到 PPT 的生成能力。当前 README 与使用文档重复，测试模板也不适合作为面向用户的设计示例。

## What Changes

- 新增独立日报示例：三类可编辑模板、五行虚构 Excel 数据、五页生成成品及页面预览。
- 采用统一的深蓝、青绿、暖白视觉主题，项目页提供手动添加实验图片的区域。
- 新增可重复生成示例的构建入口，继续使用现有生成器，不增加应用功能。
- 精简 README 与使用指南，统一示例、术语和功能边界，补充示例发布检查。

## Capabilities

### New Capabilities

- `bio-daily-example`: 蛋白表达与纯化日报的示例内容、视觉模板、可重复生成及文档入口。

### Modified Capabilities

无。现有生成行为、配置格式及测试 fixture 契约保持兼容。

## Impact

- 涉及 `examples/bio-daily/`、示例构建脚本、README、使用指南及示例验收测试。
- 沿用现有运行时依赖；不修改应用源码和现有测试 fixture。
- 与工作区正在进行的发布流程变更衔接，保留其文件和发布说明约定。
