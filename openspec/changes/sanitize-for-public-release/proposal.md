## Why

项目准备公开发布，但当前文件仍包含企业关联名称、来源于实际业务的示例编号和机器专用文件，已有 Git 历史还保留业务附件及个人信息。用户已确认公开版本不保留 Git 历史，并统一使用通用的 `AGENTS.md`，移除 `CLAUDE.md`。

## What Changes

- 清理 README、培训文档、OpenSpec 当前规格及归档文档中的企业关联、真实附件名和业务编号；保留通用技术说明。
- 删除 `CLAUDE.md`，将仍适用且必要的开发说明整合到已有 `AGENTS.md`。
- **BREAKING** 将带企业名称的生成模块和对应测试文件改为通用名称，同步导入及文档引用；不保留含旧名称的兼容模块。
- 将测试示例编号、工作表名称和提交的示例配置改为明确虚构、通用的内容，并同步共享 fixture 构造器、测试断言和二进制 fixture。
- 移除版本控制中的虚拟环境配置及 Python 缓存，补充必要忽略规则，尊重现有暂存删除。
- 准备独立的公开源码快照，排除 `.git`、机器文件和本地生成物，不改变原仓库历史；提供在新仓库中创建初始提交的发布说明。
- 按用户确认的规格复核清单，移除七份旧 YAML／双 Excel 增量规格，清理当前规格中已不适用的项目联查、默认勾选、输出页序及映射界面描述；同步 GUI 错误处理和模板标识位置说明，保持代码与测试不变。

## Capabilities

### New Capabilities

- `public-release-hygiene`: 约束公开源码、协作说明及无历史发布快照的内容和验收方式。

### Modified Capabilities

- `reproducible-test-fixtures`: 增加示例数据必须独立虚构、可公开分发的要求，继续保证构造器与二进制 fixture 语义一致。

## Impact

- 涉及生成模块及其导入方、对应测试、`tests/create_fixtures.py`、`tests/fixtures/`、`config.toml`、`.gitignore`、`AGENTS.md`、`CLAUDE.md` 和项目文档。
- GUI 操作、生成算法、Excel 列到 PPT 占位符的映射方向和配置格式保持兼容；不增加依赖，不调整现有运行时默认值。
- 公开快照不携带原 Git 提交、分支、标签或远程配置；原仓库继续保留作内部记录。
- 保留现有 MIT 许可证及公开作者署名；本变更不创建 GitHub 远程仓库、不推送、不删除或重写原仓库的 `.git`。
