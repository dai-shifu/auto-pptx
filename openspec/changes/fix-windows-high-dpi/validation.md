## 待人工验收

在相同试构建的 100% 和 150% Windows 主屏幕上，保持 exe 的兼容性覆盖关闭，运行以下检查：

1. 打开两个「浏览」弹窗，确认字体和边框清楚、文件筛选正确。
2. 选择合成模板与 Excel，确认连续数据行上下留白，中文、英文和勾选符号完整。悬停在被截断的长文本上，确认提示完整且可跨入阅读。
3. 在生成验收夹具中选「数据」、标题行 1、模板列「模板」，全选并生成。确认出现 `acceptance_unmapped` 警告，再用 `scripts.check_windows_generation verify` 检查输出。
