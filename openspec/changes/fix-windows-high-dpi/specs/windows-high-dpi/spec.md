## ADDED Requirements

### Requirement: Windows 成品默认支持系统 DPI

Windows 发布版单文件 exe SHALL 默认以系统 DPI 感知模式创建 GUI，无需用户启用高 DPI 兼容性覆盖。模板和 Excel 的「浏览」按钮 SHALL 继续打开系统原生文件对话框并保留原有文件类型筛选。

#### Scenario: 在主显示器 150% 缩放下使用成品

- **WHEN** 用户在主显示器采用 150% 系统缩放的 Windows 桌面会话中启动未设置兼容性覆盖的成品，并打开两个「浏览」对话框
- **THEN** 主窗口和两个原生对话框以系统 DPI 清晰绘制，文件筛选仍分别为 `.pptx` 和 `.xlsx`

#### Scenario: 在主显示器 100% 缩放下使用成品

- **WHEN** 用户在主显示器采用 100% 系统缩放的 Windows 桌面会话中启动未设置兼容性覆盖的成品
- **THEN** 文件对话框、预览勾选和生成流程保持可用，控件不因 DPI 修复而裁切或重叠

### Requirement: Windows 数据预览保留文字上下留白

Windows 数据预览的行高 SHALL 容纳当前主题实际字体的完整行高，并在文字上方和下方各保留至少 2 个与设备无关的像素（DIP）。本要求不改变预览列宽和水平截断规则。

#### Scenario: 在 100% 和 150% 缩放下查看连续数据行

- **WHEN** 用户分别在主显示器采用 100% 和 150% 系统缩放的 Windows 桌面会话中，加载含中文、英文字母和数字的合成数据
- **THEN** 每一行的文字和勾选符号均完整显示，相邻行的文字不贴在一起
- **AND** 用户仍可正常勾选各行，并通过悬停提示查看被水平截断的文本
